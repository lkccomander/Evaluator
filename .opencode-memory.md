## Lessons Learned
1. **Railway projects are fully isolated** — separate VPC, no inter-project networking. An orphan project can't talk to services in another project even via private networking. Public API URLs would still work, but it's not a real connection.
2. **`railway init` without flags creates a new project** — to link an existing one, use `railway link` instead.
3. **`railway project delete --project <name> -y`** — deletion is scheduled async; `deletedAt` field confirms acceptance, even if the project still appears in `list` temporarily.
