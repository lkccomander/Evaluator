# Project Context

## What is this project?

A mobile-friendly World Cup 2026 prediction game where users predict match results and compete in rankings.

## Rules

- Exact score prediction: 5 points
- Correct outcome (win/draw/loss): 2 points
- Incorrect prediction: 0 points

## Main Features

- User registration and login
- Team name for each participant
- Match calendar
- Prediction submission
- Automatic scoring
- Rankings leaderboard
- Admin panel
- Responsive mobile interface

## Tech Stack

### Frontend
- React
- TypeScript
- Bun

### Backend
- Hono
- TypeScript
- Bun

### Database
- PostgreSQL

### Deployment
- Railway

## Authentication

- JWT
- Password hashing

## Target Users

Friends, families, offices, and private groups participating in the World Cup pool.
